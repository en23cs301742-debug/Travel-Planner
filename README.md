# Personalized AI Travel Planner

A React + TypeScript + Vite frontend paired with a FastAPI backend. The planner works without an external AI key by generating a deterministic, structured itinerary locally.

## Run locally

### Backend (PowerShell)

```powershell
cd backend
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

### Frontend (a second PowerShell window)

```powershell
cd frontend
npm install
npm run dev
```

Open http://localhost:5173.

## Deploy

The included `render.yaml` deploys both services on Render. Create a new Blueprint from this repository; after the API is live, set `VITE_API_URL` on the static site to the API's public URL and redeploy the frontend. The public URLs are generated by Render and cannot be known until the deployment is created.

### Free deployment without card verification

If Render requests a payment card, deploy the backend as a Docker Space on Hugging Face and the frontend on Vercel:

1. Create a new Hugging Face Space, choose **Docker**, and set visibility to **Public**.
2. Upload the contents of `backend/` to the Space, including `Dockerfile`.
3. Wait for the Space to build. Its API URL will be `https://YOUR_USERNAME-SPACE_NAME.hf.space`.
4. Confirm `https://YOUR_USERNAME-SPACE_NAME.hf.space/api/health` returns `{"status":"ok"}`.
5. Import this repository into Vercel, set the project root to `frontend`, and set `VITE_API_URL` to the Hugging Face API URL.
6. Deploy the Vercel project. The resulting `vercel.app` URL is the frontend submission link.
